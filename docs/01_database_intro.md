# 01. 데이터베이스 개요

이 문서는 데이터베이스와 MySQL의 기본 개념을 정리하는 문서입니다.

## 데이터베이스란?

데이터베이스는 데이터를 체계적으로 저장하고 관리하는 공간입니다.

## DBMS란?

DBMS(Database Management System)는 데이터베이스를 관리하는 소프트웨어입니다.

예시:

- MySQL
- Oracle
- PostgreSQL
- SQLite

## MySQL이란?

MySQL은 관계형 데이터베이스 관리 시스템입니다.

테이블 형태로 데이터를 저장하고, SQL을 사용해 데이터를 생성·조회·수정·삭제할 수 있습니다.

## 핵심 용어

| 용어 | 의미 |
|---|---|
| Database | 데이터를 저장하는 공간 |
| Table | 데이터를 행과 열로 저장하는 구조 |
| Row | 하나의 데이터 기록 |
| Column | 데이터의 속성 |
| Primary Key | 각 행을 구분하는 고유값 |
| SQL | 데이터베이스를 다루는 언어 |
